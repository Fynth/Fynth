## Shovel

Native desktop database client. Not a browser tab, not Electron.

**SQLite · PostgreSQL · MySQL · ClickHouse** · Rust · Dioxus · ACP

Chat-first SQL with persistent threads. Multi-tab editor, schema explorer, editable result grids, CSV/JSON/XLSX import and export. Inline SQL completions and ACP agents (DeepSeek, Ollama, OpenCode) when you want them. The app still works if you ignore the AI parts.

Shipped as `.deb`, AUR (`shovel` / `shovel-bin` / `shovel-git`), Flatpak, Windows `.exe` / `.msi`. CI, supply-chain checks, MIT license. Latest release: [v0.2.3.1](https://github.com/Fynth/Shovel/releases/tag/v0.2.3.1).
