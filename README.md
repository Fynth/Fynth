## Stack

Rust is the main language. Tokio for async. Axum and Actix for HTTP. Reqwest and Serde when the service talks to other APIs. SQLx and Diesel for SQL. Dioxus and Tauri for native UI.

Go is for HTTP services. Gin, Fiber, Echo. GORM if I want an ORM.

Python is Django, DRF, FastAPI, Flask. Pydantic for schemas, SQLAlchemy for the database, Celery for background jobs, pytest for tests. Pandas for tables. Requests for simple HTTP.

C for small programs and interpreters.

### Data

PostgreSQL first. Then MySQL, SQLite, ClickHouse, Redis, MongoDB.

### Backend

REST most of the time. WebSockets when it has to stay open. gRPC between services. RabbitMQ and Kafka when work moves across processes.

### Ship

Docker and Compose. Linux, Nginx, Git, GitHub Actions.
